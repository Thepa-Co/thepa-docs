# Thépa

Thépa est une plateforme de réservation de places de cinéma. Les utilisateurs recherchent une séance, choisissent leurs sièges, effectuent un paiement simulé et obtiennent un billet. Le personnel programme les séances et contrôle les billets à l'entrée du cinéma.
